Estes celulares são meus.
These phones are mine. Estes = these Celular = phone Meu = mine
O caderno é dele.
The notebook belongs to him. Caderno = notebook Dele = him
Eu quero aquela casa.
I want that house. Querer = to want Aquela = that Casa = house
Isso é um lápis.
Is that a pencil? Isso = that Um(a) = a/an Lápis = pencil
Essas flores são suas?
Are those flowers yours? Essas = those Flores = flowers Suas = yours
